# Documentation

This folder holds the HASHI documentation site, built with [MkDocs Material](https://squidfunk.github.io/mkdocs-material/).

- [`specification.md`](specification.md) is the specification itself.
- [`topics/`](topics/) holds explanatory guides.

## Building Locally

```bash
pip install -r requirements-docs.txt
mkdocs serve
```

Then open <http://127.0.0.1:8000>.
