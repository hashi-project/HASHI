# Governance

HASHI is at an early stage and is run by its editor.

## Roles

- **Editor.** Owns the specification, decides what is merged, and sets version numbers.
- **Maintainers.** Review issues and pull requests. Listed in [MAINTAINERS.md](MAINTAINERS.md).
- **Contributors.** Anyone who opens an issue or pull request.

## Decisions

Proposals are discussed in issues. Significant design decisions are recorded as Architecture Decision Records in [`adrs/`](adrs/). The editor makes the final call.

## Changes to Governance

As the project grows, this model is expected to move towards a more open, multi-maintainer structure. Any change to governance will be proposed in an issue first.
